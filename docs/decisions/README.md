# تاریخِ تصمیم‌های فنی

هر فایل یک تصمیم است. هدف: شش ماه بعد جوابِ «چرا این‌جوری زده شده؟» نوشته
باشد — به‌خصوص **گزینه‌هایی که رد شدند و دلیلشان**، که هیچ‌وقت از خواندنِ کد
فهمیده نمی‌شود.

## وضعیت‌ها

- ⏳ **پیشنهادی** — نوشته شده، ولی تأیید نشده. کدی بر مبنایش نوشته نمی‌شود.
- ✅ **پذیرفته‌شده** — تأیید شده، مبنای کار است.
- ↩️ **جایگزین‌شده با ۰۰۰X** — عوض شده. سندِ قدیمی پاک نمی‌شود.
