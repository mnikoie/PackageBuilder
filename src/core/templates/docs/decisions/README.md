# تاریخِ تصمیم‌های فنی

هر فایل در این پوشه یک تصمیمِ فنی است. هدف این است که شش ماه بعد، وقتی کسی
(یا خودت) پرسید «چرا این‌جوری زده شده؟»، جواب نوشته شده باشد — به‌خصوص
**گزینه‌هایی که رد شدند و دلیلِ ردشدنشان**، که همان چیزی است که هیچ‌وقت از
خواندنِ کد فهمیده نمی‌شود.

## نام‌گذاری

`0001-open-decisions.md`، `0002-choose-database.md`، … شماره‌ها ترتیبی و
تغییرناپذیرند. سندِ قدیمی را پاک نکن؛ اگر تصمیمی عوض شد، سندِ جدید بساز و
وضعیتِ قدیمی را به «جایگزین‌شده با ۰۰۰۷» تغییر بده. تاریخِ تصمیم‌ها به همان
اندازهٔ خودِ تصمیم‌ها ارزش دارد.

## قالب

```markdown
# ۰۰۰۲ — <موضوع>

- **تاریخ:** ۱۴۰۵/۰۵/۲۷
- **وضعیت:** پیشنهادی | پذیرفته‌شده | جایگزین‌شده با ۰۰۰۷

## زمینه
چه مشکلی؟ چه محدودیتی (بودجه، زمان، دانشِ تیم، فارسی/RTL، حجمِ داده)؟

## تصمیم
چه چیزی انتخاب شد.

## گزینه‌های دیگر
| گزینه | مزیت | چرا رد شد |
|---|---|---|

## پیامدها
چه چیزی سخت‌تر می‌شود، چه چیزی آسان‌تر، و برگشت از این تصمیم چقدر گران است.
```
