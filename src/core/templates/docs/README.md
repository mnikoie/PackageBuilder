# مستندات

| پوشه | چیست |
|---|---|
| `decisions/` | تاریخِ تصمیم‌های فنی — چه چیزی، چه وقت، و چرا |

جای چیزهایی که بعداً لازم می‌شوند هم همین‌جاست: راهنمای راه‌اندازیِ محیطِ
توسعه، شرحِ معماری، دفترچهٔ عملیات (چطور دیپلوی/بازیابی کنیم). تا وقتی
تکنولوژی انتخاب نشده، هیچ‌کدام از این‌ها قابلِ نوشتن نیستند.
