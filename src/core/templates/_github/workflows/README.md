# CI

**عمداً خالی است.** فایلِ workflow باید دستورهای واقعیِ همین پروژه را اجرا
کند (lint، typecheck، build، test). تا وقتی زبان و مدیرِ پکیج انتخاب
نشده‌اند، آن دستورها وجود ندارند و هر `ci.yml`ای که الان نوشته شود، یک
workflowِ همیشه-قرمز یا همیشه-الکی-سبز است.

بعد از تصمیم‌های ۱ و ۲، یک `ci.yml` بساز که **دقیقاً همان** دستورهایی را
اجرا کند که خودت لوکال می‌زنی — نه بیشتر، نه کمتر. اگر CI و لوکال دو چیزِ
متفاوت اجرا کنند، سبزبودنِ CI بی‌معنا می‌شود.
