# اسکریپت‌ها

کارهای تکراری که با دست انجام می‌دهی، همین‌جا تبدیل به اسکریپت می‌شوند:
راه‌اندازیِ اولیه، مهاجرتِ دیتابیس، تولیدِ کد، پشتیبان‌گیری.

**عمداً خالی است.** زبانِ این اسکریپت‌ها به تصمیمِ شمارهٔ ۱ در
`docs/decisions/` بستگی دارد — اگر Node انتخاب شود `.mjs`، اگر پایتون
`.py`، و مستقل از هرچیز ممکن است `.ps1`.

قاعده: هر اسکریپت باید در چند خطِ اولش بنویسد چه کار می‌کند و چطور اجرا
می‌شود، و اجرای دوباره‌اش نباید چیزی را خراب کند.
