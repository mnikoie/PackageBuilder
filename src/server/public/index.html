«نامعلوم» با «نیست» یکی نیست. اگر Docker بالا نباشد، وضعیتِ سرویس‌ها نامعلوم است — نه «نصب نیست». نسخهٔ قبلیِ این ابزار همین دو را قاطی می‌کرد و چیزهای نصب‌نشده را سبز نشان می‌داد.
